## Scope (exact diff)

New:
- `src/main/java/mekanism/common/lib/transmitter/acceptor/FluidAcceptorCache.java` — per-pipe fresh fluid cache. `AcceptorInfo` stores only lookup context (owning `TileEntityTransmitter`, initialized `ServerLevel`, neighbor pos, opposite face); each `acceptor()` validates tile removal/loading (`isRemoved`/`isLoaded`, the same owner `Transmitter.isValid()` uses), tile level identity against the initialized server level, and `WorldUtils.isChunkLoaded` on the neighbor before a fresh `FluidStorage.SIDED.find(level, pos, opposite)`. No returned `Storage` retained, no `BlockCapabilityCache`, no invented level lifecycle API, no global unload hook, no refresh listener consumed (rediscovery is via the official bitmap refresh callers). (REVIEW_09 correction: the previous version called nonexistent `ServerLevel.isRemoved()`.)

All public readers (`getAcceptorValues/getAcceptorCount/hasAcceptor/getCachedAcceptor/getAcceptorDirections/getAcceptorFastIterator`) build a detached ephemeral `pos -> face -> Storage` snapshot per read: for each valid, non-remote, loaded member pipe, all six sides — `refreshAcceptorConnections(side)` (official bitmap/packet policy) then `canConnectToAcceptor(side)` (canSendTo) then bitmap-gated `getAcceptor(side)` fresh lookup; keyed at `WorldUtils.relativePos(pipePos, side)` under `side.getOpposite()`. `updateTransmitterOnSide` override = bitmap refresh only (no retained map writes). `adoptAcceptors` override = `adoptPendingDirty` only (no Storage copy; membership re-read post-merge). `getAcceptorDirections` returns detached `EnumSet.copyOf`/empty — never a view. Client/no-world reads see no member pipes → empty, no chunk loading.
