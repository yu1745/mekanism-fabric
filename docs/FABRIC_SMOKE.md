# Packaged Fabric server smoke test

Run the final, remapped JAR in a clean dedicated server rather than Loom's development classpath:

```bash
scripts/fabric-packaged-smoke.sh
```

The script reads the pinned Minecraft, Loader, Fabric API, and Fabric Installer versions from `fabric/gradle.properties`, builds `remapJar`, downloads reusable dependencies into `${XDG_CACHE_HOME:-~/.cache}/mekanism-fabric-smoke`, and creates an EULA-accepted server only under a temporary directory. The audited slices contain API **42** / common **80** / platform **10** unique sources. The script rejects a mod JAR containing `net/neoforged/` or integration-fixture classes; verifies exact common/client entrypoint metadata and the single intended remapped access-widener entry plus packaged networking, energy-container, basic and variable heat-capacitor, relative-side, holder, and unchanged `WildcardMatcher` classes. Direct `mekanism/common/lib/*.class` entries are
restricted exactly to byte-identical `Color.class`, `Color$ColorFunction.class`, `WildcardMatcher.class`, and `LastEnergyTracker.class`, once each. Exact nested families additionally contain only `CustomEffect.class`; `Pos3D.class`, `Quaternion.class`, and `Range3D.class`; the `MultipartUtils` outer and two nested classes; and `StatUtils.class`, rejecting task test/helper leakage. Their 12 Java 21 tests bound color/stat/effect/spatial/quaternion/direct-ray semantics without a startup marker. All renderers/particles/GUI/recipe viewers/client lifecycle, transmitters/multipart blocks/gear, machines/block types/entities, packet tracking/network ranges, SPS/multiblock, additions/generators, external energy, world/chunk lifecycle, registries/config/persistence callers/owners remain deferred; this gate makes no rendering integration, entity/player lifecycle, block registration, networking, thread-safety, or collision-owner guarantee. It also requires exactly one entry each for `EmitUtils`, `SplitInfo`, `IntegerSplitInfo`, `LongSplitInfo`, `Target`, and `Target$HandlerType`, exactly one `mekanism/common/util/ChunkUtils.class`, and exactly one entry for the `LambdaMetaFactoryUtil` outer class, `CallSiteInfo`, and all five private primitive setter interfaces. It additionally requires exactly 12 `mekanism/common/lib/collection/*.class` entries: the previous six plus `BiMultimap`, `EmptySequencedMap`, `HashList`, `LRU`, `LRU$LRUEntry`, and `LRU$LRUIterator`, each once, while rejecting every other class in that package, and exactly one `RegistryUtils.class` and rejects every other `RegistryUtils*.class`, requires exactly one entry each for `mekanism/api/container/InContainerGetterLong.class`, `mekanism/api/container/LongToLongContainerInteraction.class`, and `mekanism/api/math/LongTransferUtils.class` while rejecting every other `LongTransferUtils*.class`, requires the three strict energy-handler interfaces and `IEnergyContainer` exactly once while rejecting every other energy API class, restricts direct `mekanism/common/capabilities/*.class` entries exactly to `SimpleDynamicHandler` and `DynamicHandler`, and restricts direct energy implementation entries exactly to `BasicEnergyContainer` and `DynamicStrictEnergyHandler`, all once. Every unexpected distribution, `ChunkUtils*`, `LambdaMetaFactoryUtil*`, or `LongTransferUtils*` class is likewise rejected so official/local test and helper classes cannot leak into the release JAR. It passes only after the server log lists mod id `mekanism`, records the clean `values=12` startup-config proof, records configuration-network registration for exact protocol `10.7.19`, parses `config/Mekanism/startup.toml` and compares all paths/defaults exactly, records the `entries=4` canonical proof for all official Mekanism GameEvents, invokes the access-widened position-adjusted biome-temperature path and records its finite-result heat proof, and reports `Done (`. The server process and temporary directory are removed on every exit.

Diagnostic logs are retained under `build/fabric-packaged-smoke/<UTC timestamp>-<pid>/`. Set `FABRIC_SMOKE_KEEP_SERVER=1` to retain the disposable server directory as well. Other useful overrides are `FABRIC_SMOKE_TIMEOUT`, `FABRIC_SMOKE_CACHE_DIR`, `FABRIC_SMOKE_LOG_DIR`, and `FABRIC_INSTALLER_VERSION`.
