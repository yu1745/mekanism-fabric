# Packaged Fabric server smoke test

Run the final, remapped JAR in a clean dedicated server rather than Loom's development classpath:

```bash
scripts/fabric-packaged-smoke.sh
```

The script reads the pinned Minecraft, Loader, Fabric API, Team Reborn Energy, and Fabric Installer versions from `fabric/gradle.properties`, builds `remapJar`, downloads reusable dependencies into `${XDG_CACHE_HOME:-~/.cache}/mekanism-fabric-smoke`, and creates an EULA-accepted server only under a temporary directory. The audited slices contain API **43** / common **88** / platform **14** unique sources. It fetches exactly `https://maven.fabricmc.net/teamreborn/energy/4.1.0/energy-4.1.0.jar`, validates mod id/version and `team/reborn/energy/api/EnergyStorage.class`, installs it beside Fabric API and Mekanism, and records the version. The script rejects a Mekanism JAR containing `net/neoforged/`, `team/reborn/`, or integration-fixture classes; verifies exact common/client entrypoint metadata and the single intended remapped access-widener entry plus packaged networking, energy-container, basic and variable heat-capacitor, relative-side, holder, and unchanged `WildcardMatcher` classes.
