## Parent review corrections (2026-09-14, follow-up commit on 826756fb)

The review rejected three claims in the initial closeout, each fixed with production code and test evidence (no new test methods; existing ones extended):

1. **`FabricEnergyStorage.stableHandler()` returned the raw `handler`**, so a reverse-unwrap `FabricEnergyLookup.wrap(exposed, NORTH, sameConversion)` retained **before** `invalidate()` kept live owner access (the old test only wrapped after invalidation). Fixed with the stable revocable `StableJoulesHandler` Joules-domain facade: exact Joules semantics survive (direct delegation, no FE roundtrip), all domain reads/writes/transfers fail closed after `invalidate()`, and the raw backing handler stays unguarded so `readSnapshot` rollback remains valid. `FabricEnergyLifetimeTest` now retains the reverse handler first and proves no old-owner read/mutation, and the rollback test still restores through the revoked view.
2. **`revokeHandler` default claimed chemical/heat proxies staying live was safe** — wrong owner lifetime: retained `ProxyChemicalHandler`/`ProxyHeatHandler` delegates could still read/mutate the removed owner. Fixed by permanent revocation in those proxy surfaces (plus item/fluid/energy proxy surfaces for the read-only domain views), `ChemicalHandlerManager`/`HeatHandlerManager` `revokeHandler` overrides, revoke-before-cache-removal ordering, and an unsupported-identity guard so wrong-lookup invalidation never revokes unrelated cache. Official active proxy behavior including the null-side read-only proxy is preserved; no heat holder insertion policy invented. `HandlerManagerTest` chemical/heat case now checks retained-before-invalidation mutations and read access with call counters.
3. **Plan-required explicit internal read-only domain access for item/fluid/energy was missing** (managers only exposed mutable `getInternal()`/`getContainers`). Fixed with lazy typed `getReadOnlyHandler()` on `ItemHandlerManager` (`ProxyItemHandler`/`ISidedItemHandler`), `FluidHandlerManager` (`ProxyFluidHandler`/`IExtendedFluidHandler`), and `EnergyHandlerManager` (`ProxyStrictEnergyHandler`/`IStrictEnergyHandler`), revoked by null-side invalidation/`invalidateAll()`, with `getInternal()` kept and no external null Storage exposure. Manager tests prove domain reads, denied writes, cache replacement, and retained revocation.

Correction-agent checks: `compileJava`/`compileTestJava`, the two focused test classes (6 tests) green, `gradlew -p fabric assemble` green.
