## Smoke probe facts (not recorded elsewhere)

Written via `data merge block` in `scripts/fabric-machine-smoke.sh` and any new probes:

- Inventory slots: `items:[{slot:0b,item:{id:"minecraft:iron_ore",count:2}}]`
- Energy containers: `energy_containers:[{container:0b,stored:20000L}]`
- Fluid tanks: `fluid_tanks:[{tank:0b,stored:{id:"minecraft:water",amount:8000}}]`
- Chemical tanks: `chemical_tanks:[{tank:0b,stored:{id:"mekanism:oxygen",amount:8000}}]` — the field is `id`, not `chemical`.
- Machine per-side config lives in `component_config` as `config<ordinal>` int arrays in `RelativeSide` order (FRONT, LEFT, RIGHT, BACK, TOP, BOTTOM) plus `eject<ordinal>` booleans; transmission ordinals ENERGY=0, FLUID=1, CHEMICAL=2, ITEM=3, HEAT=4. With `facing=north`, east→LEFT and west→RIGHT. `/setblock` does not apply item components, so these tags must always be written explicitly.
- Transmitter side connections use the `connection` int array (Direction order) documented in `docs/API_DELTAS.md`.

## Open gaps

1. **Chemical auto-eject does not deliver.** With the separator's chemical output on LEFT (`eject2`) and 200,000 J, hydrogen/oxygen accumulate in its internal tanks but nothing reaches an adjacent `basic_chemical_tank`. Item ejection (chamber → chest) works with the same mechanism, so the defect is specific to the chemical branch (`TileComponentEjector` → `getChemicalCapabilityCaches` → `ChemicalUtil.emit`) or the target tank's side acceptance. Under investigation.
2. **Client lane entirely unported**: bootstrap/entrypoints, GUI screens/containers, item/fluid/chemical rendering, MekaSuit/armor renderers. Without it, players cannot configure sides/GUIs normally.
3. **Worldgen ores**: the generated `worldgen/configured_feature`/`placed_feature` JSONs exist, but NeoForge's `neoforge/biome_modifier` datapack registry has no Fabric counterpart, so ores do not generate. Ruling recorded in the plan below.
4. **Automation parity**: vanilla hoppers cannot insert into Mekanism machines (vanilla `Container` vs `ItemStorage.SIDED`); needs a Mekanism-specific hopper adapter.
5. **Datagen/compat recipes**: 637 `compat/**` and 320 NeoForge-shape recipes deferred to the datagen/compat lane.
